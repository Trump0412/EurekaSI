# Security policy

Do not report credentials, private dataset locations, unpublished checkpoints, or access tokens in a public issue.

For a public GitHub release, enable private vulnerability reporting in the repository settings and use that channel for suspected command injection, unsafe archive extraction, credential exposure, or dependency-chain issues. Until a private channel is configured, remove sensitive details and contact a maintainer privately.

Only the latest source revision is supported for security fixes. Model behavior, benchmark outputs, and generated actions are research results and are not security or safety guarantees.
