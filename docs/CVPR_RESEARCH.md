# CVPR 研究方案：什么训练带来可迁移的空间智能？

## 判断

**值得做，但“Qwen3-VL-2B 在 SPAR + LLaVA-Hound SFT 后 VSI 下降”是待解释的现象，不足以推出训练数据脏，更不足以独立构成论文。** 有价值的主张应是：哪些数据、监督与表征使模型获得对视觉证据敏感、跨参照系一致、可迁移到行动的空间能力；在什么条件下常用空间 QA 训练反而破坏它。

建议工作题目：*When Spatial Supervision Fails: Learning Transferable Spatial Intelligence*。这是工作标题，不是已有论文名称。

## 与已有工作区分

- [ReVSI](https://3dlg-hcvc.github.io/revsi/) 已系统讨论 VSI 的评测有效性问题。因此单做“发现旧 benchmark 或标注有问题”难以构成足够新意，应同时使用 ReVSI 和不共享场景的另一类任务。
- [GeoThinker](https://arxiv.org/abs/2602.06037) 研究主动、按需的几何融合，并报告具身指代和驾驶泛化；[GeoSR](https://github.com/SuhZhang/GeoSR) 研究几何利用不足；[SpatialStack](https://github.com/jzh15/SpatialStack) 研究分层几何语言融合。单加一个 VGGT 或门控也不构成清楚的新贡献。
- [DSR Suite](https://github.com/TencentARC/DSR_Suite) 已有动态空间监督与数据构建。新研究应将“空间监督质量—证据依赖—能力迁移”形成可证伪的完整链条。

## 空间智能的操作性定义

模型能够从多视角/时序视觉证据形成在参照系转换与场景变化下保持一致的实体—关系—状态表征，并用它完成几何判断、变化预测或行动决策。该定义是本研究拟检验的操作性定义，不宣称领域已有统一定义。

| 维度 | 证据与任务 | 关键反证 |
|---|---|---|
| 度量几何 | 距离、尺度、深度、布局 | 换物体类别仍能预测，不仅记忆类别平均尺寸 |
| 参照系 | 相机/物体/世界坐标转换 | 视角改变后答案按几何规律变化 |
| 多视图一致性 | 遮挡、身份对应、跨帧关系 | 多视图优于单帧；错配视图应损害需要它的任务 |
| 动态空间 | 运动、关系变化、事件顺序 | 反转顺序只影响真正依赖时间的题 |
| 组合泛化 | 新对象、新关系组合、多跳 | 未见场景和组合仍有效，不能由语言先验解释 |
| 可操作性 | 指代、操作、规划或状态预测 | QA 增益能够解释下游增益，而非仅格式正确率提高 |

不建议先给这六个维度任意加权拼出“空间智能总分”。先报告能力向量、跨任务一致性和迁移，再讨论是否存在共同因子。

## 第一阶段：解释 SFT 降分，先不清数据

固定原始模型 revision，保存原始基模和 SFT checkpoint；同一清单、同一帧、图像预算、chat template、解码上限、答案解析与 official scorer。至少复查以下原因：

1. **数据构建错位**：SPAR 彩点/框没有渲染；帧索引与 marker 不一致；视频路径找错；answer 标签丢零；选项丢失；重复图像或题目实体不可见。
2. **监督目标变化**：长描述/字幕监督占优；答案包裹格式改变；全序列 labels 误训练用户 prompt；EOS/截断；assistant mask 与 tokenizer 不匹配。
3. **优化与容量**：2B 容量、LoRA 层、学习率/步数、视觉塔冻结策略、数据比例；训练损失下降不代表空间能力上升。
4. **遗忘与分布偏移**：通用视频语义偏好挤压空间能力；短帧训练长帧评测；静态监督不能覆盖动态问题。
5. **评测问题**：VSI 与 ReVSI 的题目/视觉证据差异，框架 prompt 和处理版本变化、解析率下降、覆盖率变化。

基线至少 Base / SPAR-only / Hound-only / SPAR+Hound，3 seeds；每组保留早中晚 checkpoint。先用少量分层 QA 人工逐例核对，再扩大。不要用测试集选择清洗规则或学习率。记录 generic parse rate 与 official metric 分别发生的变化。

## 第二阶段：建立数据能力与质量标签

按真实场景、视频来源、相机轨迹和语义模板族去重分组，先固定 train/validation/test。使用独立双人标注子集确认自动清洗规则的 precision/recall，报告标注分歧，而非让同一个 teacher 自问自答认证所有样本。

质量分轴：视觉证据充分性、几何金标准可验证性、参照系明确性、时序要求、语言捷径强度、选项歧义、标记/帧对齐、跨集合污染。能力分轴见上表。真实有用的训练数据应覆盖能力与证据类型，不等于题干包含“left/distance/spatial”。

清洗对照必须包括：原始数据、随机删到同规模、仅工程修复、语义质量过滤、能力均衡采样、困难样本保留。只有“清洗组优于原始组”不足以区分少训、重新配比和质量贡献。训练 token、样本、图像预算分别记录；固定一种主预算，另报实际 FLOPs/时长和 token。

## 第三阶段：监督和蒸馏

| 组别 | 初始模型 | 可回答的问题 |
|---|---|---|
| SFT | 相同 base | 高质量监督本身有什么贡献？ |
| RL（GRPO/GSPO） | 同一 SFT | 结果奖励是否改善泛化，还是只延长推理/学格式？ |
| OPD | 同一 SFT，兼容 tokenizer 教师 | 强空间教师的条件分布能否迁移？ |
| OPSD | 同一 SFT，答案条件 teacher | 训练期特权答案是否有效，而推理输入仍不泄漏？ |
| 异构序列 KD | 同一 SFT，不同 tokenizer 教师 | 教师输出文本贡献；不混称为 token-level OPD |
| 几何融合 | 相同数据/优化预算 | 几何证据还是额外参数造成变化？ |

蒸馏教师优先选择公开权重、可本地加载、与学生 tokenizer 相容的模型。GeoThinker 等带专用几何模块的 teacher 不能去掉模块后仍用同一个名字报告。记录 teacher 的输入模态、帧数、geometry、prompt、temperature、checkpoint 和采样 token。教师同场景训练污染不能通过下载公开权重排除。

## 第四阶段：因果证据和迁移

最小证据干预：正确图像、问题-only、错配场景、单帧、多视图顺序反转、参照系变换、几何关闭/错配、参数量匹配的无几何模块。干预是否应该改变答案必须按任务定义；对计数题乱序不一定应降分，不能强行解释为模型忽略视觉。

应用先选具身指代，再选一个 LIBERO suite 的冻结 encoder + 相同 BC/action head。如果问答涨分但动作无提升，也可能是动作接口、时延或训练覆盖不足；进一步分析表征预测能力，不直接宣布空间能力“无用”。自动驾驶和世界模型可作为后续扩展，避免首篇范围失控。

## 统计与停止条件

使用按 scene/video 聚类的配对 bootstrap，而不是把同一场景的几十题当独立样本。`spatial paired --a RUN_A --b RUN_B --output ci.json` 对相同协议的通用逐例正确率提供聚类区间；官方聚合指标需在每次 bootstrap 内重跑官方 aggregator，现工具不冒充其区间。至少 3 个训练 seeds；报告原始 seed 结果及均值，不用题目 bootstrap 代替训练不确定性。

预先确定主评测任务和主比较，探索性子任务明确标注，避免海量超参后只报最佳数值。若工程修复已完全解释降分，则转为“监督对齐与能力测量”的研究，不能继续主张所有空间数据不可靠。如果跨数据集、跨模型规模、跨 seed 均不复现降分，也应缩小主张。

## 推荐交付与阶段门槛

- A：可复现降分 + 排除构建/评分错误；决定机制是否存在。
- B：可公开的数据审计子集、能力标签、冻结划分、人工质量验证；决定清洗规则是否可信。
- C：预算匹配的 SFT/RL/OPD 对照 + 视觉证据干预；决定改进来自哪里。
- D：至少一个未参与训练和规则选择的空间 benchmark，以及一个控制动作 head 的迁移实验。

达到 A–D 才形成有说服力的研究闭环。当前代码库提供实验基础，尚无上述新的实验结果、人工数据标注、GPU 预算测量或投稿录用保证。
