# GAP-4D 奖励活性审计与修复边界

日期：2026-09-28。旧权重、原始输出和分数保留；不修改正在运行的不可变快照。

## 已证实的问题

- full / answer-only / answer+format 各 5,885 updates、94,160 prompt groups、
  753,280 responses；保存的 structure 与 words 得分均为零。
- 主实验的答案正确性确实获得奖励，但配置文件里的两个 shaping 权重没有形成
  实际训练信号。非零 loss、梯度和答案组内方差不能证明每个奖励项有效。
- 训练中存在极少数标题或标签碎片，不等于完整三段式输出：full 中有一次
  `Spatial Observation` 命中，但该回答达到 512-token 上限且截断。
- 保存的 token `[32, 151645]` 原样解码为 `A<|im_end|>`，不是摘要器提取的 A。
  当前 tokenizer 的 skip_special_tokens 保留 `<think>`、`</think>` 和 answer 标签。
- 对当前 Qwen3-VL-2B-Instruct processor，enable_thinking=True/False 的模板结果相同，
  格式指令存在，assistant 前缀没有注入空 think。不能把该参数作为未经验证的修复。
- full 的 rollout micro 为 4，两个消融为 8；后两者首步同题的第六个采样答案
  已经不同。奖励均未激活时，这些差异不能解释为奖励项的因果效果；具体数值、
  内核或环境差异尚未唯一定位，不声称逐位复现。

## 机制判断与未验证项

严格完整格式判定是一个不连续的门；words 又要求结构成立和完全正确。
短答案初始化可以通过裸字母直接获得答案分，却几乎采不到完整格式。
已观测到的失败链条是：没有合格结构 → format=0 → words=0 → 实际答案奖励训练。
SFT 的短答案偏好、格式门过稀和策略探索不足是优先验证的解释，而非已隔离的唯一根因。

旧的奖励消融无法靠重新计分修复；轨迹中没有获得过的奖励不能补成过去的训练梯度。
DSR 分数仍是这些权重的可记录输出，但不能支撑“词表增强了推理”的结论。

## 已实现的防复发措施

`spatial_intelligence/rft_reward_activity.py` 检查奖励分解、正奖励出现次数，以及
移除各 shaping 项是否改变组内标准化 advantage。恒定的格式分不能冒充有效区分信号。

训练器记录逐步累计活性；新版 gate 对启用但未生效的 shaping 项拒绝放行。
每次进程运行/续训观察满 100 次更新仍无活性时，各 rank 一致停止并记录原因。
这是必要的工程门，不是推理正确性证明；续训窗口不冒充全历史统计。
旧运行快照不会自动获得新门，必须部署新版本并重新验收。

离线复核命令：

```bash
python scripts/audit-rft-reward-activity.py --train-root "$TRAIN_OUTPUT" \
  --output "$NEW_AUDIT_JSON"
python -m unittest discover -s tests -p test_rft_reward_activity.py -v
```

审计拒绝重复组和不完整的 G；结果单列日志覆盖率，不把残缺日志当全量。
不重算或改写旧分数，不改奖励公式。当前新增 6 项 CPU 测试通过；新训练器门的
真实多卡端到端验收尚未进行。

## 真正修复训练行为的分阶段方案（尚未启动）

1. 固定训练/验证隔离的小型真实视频诊断集，先重建经过 processor 和 geometry
   insertion 的实际 input_ids，保存解码后的完整文本尾部及输出 token。
   对比原模板与明确字面序列化的模板；不在测试集挑 prompt，不强制伪造模型解释。
2. 若提示修改仍不能产生结构化输出，用训练视频配套、人工核验或可追溯教师生成的
   简短视觉证据/变化/结论说明做小规模冷启动。禁止把正确选项套进空泛三句话当作
   真实推理监督。所有奖励消融共享这一个 initializer。
3. 在新 reward 版本中评估分项格式得分（合法外壳、字段顺序、非空内容）以降低
   全有或全无的探索门槛；答案计分仍独立。保留完整格式率作为正式指标，不能靠
   放宽 parser 把散文或复述模板计成正确。words 门控与词表防刷策略单独记录。
4. 先做小预算真实 G8 pilot，确认每项奖励的正值、组内差异、实际 advantage 影响，
   并人工检查解释是否与视频相关。未通过不启动三组全量训练。
5. 三组均从同一新 initializer 重新开始，统一 prompt、micro、软件精度、预算和
   样本顺序。保留原始回答与分项奖励；只改变奖励权重。full 也必须重跑，不能
   与旧 full 拼成新消融表。

不建议直接强制所有裸答案为零：在当前输出分布下可能让所有奖励都为零。
也不把增大格式权重当修复：零乘任何权重仍是零。格式正确只代表序列化遵循，
不能单独证明模型产生了更可靠的视觉推理。
