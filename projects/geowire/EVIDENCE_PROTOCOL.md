# GeoWire 指标与可视化证据契约

从交接候选中吸收可复用的协议约束；本文件不发布候选中的私有实验分数，也不表示已有对应可运行工具。两个候选可视化脚本依赖旧 `_bootstrap`、内部 graph/cache 类型和模型状态，暂不原样迁入。

## 定量结果

- 分别记录 full graph、self-loop、随机拓扑、端点置乱的重建指标和相对 full graph 的差值。共享权重、样本、mask 与 seed；不能用 self-loop 推理冒充原方法完整几何路径。
- 对应点指标需要说明 ground truth 来自独立深度/位姿/内参，还是由被比较的几何模型自己生成。模型自身投影不能自动当作独立真值。
- 若采用候选的 PCK@0.1 定义，阈值是原图最大边长的 0.1 倍；cycle error 以同一最大边长归一化。保留图像 resize/crop 到原像素的转换、遮挡/可见性规则、有效分母和 scene-cluster 汇总。候选未完整定义 R@1 的候选集合与正例规则，因此不登记为已实现的公共指标。
- 同场景训练污染、少量 frame pair 和训练过程中的诊断不能支持 heldout 泛化结论。评测场景应来自固定清单，不在查看热图后筛选“最好看”的样本。

## 可视化

- VGGT track 密度、Qwen 最后 token 的视觉 attention、沿图边传播的 routed score 和 residual feature delta 是不同信号，应分别命名，不能统一称为“模型注意力”。
- 候选默认把 transport gate 乘以 128 再展示。此操作改变了模型计算，不能只称为颜色增强；若保留，必须记录原 gate/倍率及参数，并与原 checkpoint 的未改动输出并列。定量评测必须使用未放大的参数。
- 默认保持训练参数原值；若做纯显示用的分位数截断、逐帧归一化或 alpha overlay，保存原始数值和显示参数，避免图像色差冒充幅度差异。
- 跨模型 PCA 对比需要声明是否使用同一投影基；分别拟合并独立归一化的 RGB 色图不能证明表示对齐或改善。
- 产物应包含 checkpoint、图、视觉帧、问题、源码/协议哈希；源图缓存与可视化输出使用新目录，不能覆盖评测证据。

未来的方法工具放在 `projects/geowire/tools/`，先适配固定公开源码和公共 manifest，再对坐标映射、数据身份与参数不变性做回归。原候选和私有日志继续只保存在本地交接包中。
